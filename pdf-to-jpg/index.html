    Choosing a resolution

    A PDF page has no resolution of its own — it is a set of drawing instructions. Turning it into an image means deciding how finely to draw it, and that is what dpi means here.

    • 72–96 dpi — for a screen: a web page, a slide, a WhatsApp message. An A4 page comes out about 800 px wide.
    • 150 dpi — a good default. Sharp on a high-density phone screen, still a sensible file size.
    • 300 dpi — print quality. An A4 page becomes roughly 2480 × 3508 px, and the files get big.

    Very large pages are capped so that a single image cannot exhaust your browser's memory. If that cap kicks in, Kagaz says so rather than silently producing something different from what you asked for.

    JPG or PNG?

    Choose JPG for pages that are mostly photographs or scans — it is dramatically smaller and the loss is invisible. Choose PNG for diagrams, screenshots, charts and pages of text, where JPG's compression leaves faint smudges around sharp edges.

    Common questions

    Are my files uploaded?

    No. Rendering is done by pdf.js in your browser. There is no server behind this page.

    Why do I get a ZIP?

    A one-page conversion downloads as a plain image. More than one page is packed into a ZIP, because a browser can only hand you one download at a time.

    Can I go the other way, images into a PDF?

    Not yet — it is written up as a good first issue if you would like to build it.
