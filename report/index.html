What makes a report actually useful

You do not need to write a good bug report — anything at all is better than silence. But if you have thirty seconds spare, these are the things that turn "it didn't work" into a fix:

  • What you expected versus what happened. "The download never started" tells me far more than "it's broken".
  • Roughly how big the file was, and how many pages. Most failures are memory or size related.
  • Whether it happens every time or just once.
  • A screenshot, if there was an error message on screen.

Please do not send me the document itself — especially not the kind of document you'd be using Kagaz for. If a file is needed to reproduce a problem, I will ask, and only ever for something you have made up for the purpose.
