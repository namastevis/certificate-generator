    The four methods

    Extract pages

    Keeps only the pages you list and gives you one PDF back. Type ranges the way you would say them: 1-3, 8, 12- means the first three pages, page eight, and everything from twelve to the end.

    Every N pages

    Chops the file into equal chunks. This is the one to use when you have scanned a stack of documents that are all the same length — twenty two-page invoices become twenty files.

    One per page

    Explodes the document into a single PDF per page, numbered and zipped.

    Split at pages

    For a stack of documents of uneven length. Tell it which pages start a new document and it cuts there — list 5, 9, 14 and you get pages 1–4, 5–8, 9–13 and 14 to the end.

    Common questions

    Are my files uploaded?

    No. There is no server. Open the Network tab in your browser's developer tools and split something — nothing goes out.

    Why do I get a ZIP?

    Browsers can only offer one download at a time, so when a split produces more than one file Kagaz packs them into a ZIP. A single-file result downloads as a plain PDF.

    Do the split files keep their quality?

    Yes. Pages are copied, not re-rendered, so text stays selectable and images are untouched.
