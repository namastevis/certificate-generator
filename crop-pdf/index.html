Cropping hides, it does not delete

This is the one thing worth understanding. A PDF page has a visible area — the crop box — and changing it is like putting a mask over the page. Everything outside the mask is still inside the file, and anyone can bring it back by widening the crop.

So cropping is perfect for tidying margins and useless for hiding anything. If there is something on the page that must not be seen, use Redact PDF, which removes the underlying content for real.

Why margins are set as percentages

Because a document can mix page sizes, and "trim 20 mm" means something different on A5 and A3. A percentage of each page's own width does the sensible thing everywhere.

Common questions

Is my file uploaded?

No. The preview is rendered in your browser and so is the cropped file. There is no server.

Will the text get smaller?

No. Cropping does not scale anything. The page becomes smaller, so when a reader fits it to your screen the text ends up looking larger — which is usually the point.

Can I crop each page differently?

One crop is applied to every selected page. Per-page cropping is a good first issue.
