Skipping a cover page

The usual want is a report where page one is a title page that should stay bare, and the numbering starts on the page after it. Set pages to 2- and start at to 1. The cover is left alone and the following page is numbered 1.

If instead you want the cover counted but not printed, set start at 2.

A word on where they land

Numbers are placed relative to each page's own edges, so a document with mixed page sizes still gets them in the right corner on every page. If a number lands on top of existing content, increase the distance from the edge.

Common questions

Is my file uploaded?

No. The numbers are drawn onto the pages in your browser. There is no server.

Can I take them off again?

No. Once added they are part of the page, exactly like any other text. Keep your original file if there is any chance you will want it back.

Can I use Roman numerals or a custom font?

Not yet. Both are good first issues if you would like to add them.
