In-browser test bench

tests/stress.mjs covers the PDF logic in Node. This page covers what Node cannot: the real canvas image codec, createImageBitmap, blob encoding and the download path — in the browser you are actually shipping to.

What this checks that Node cannot

  • That createImageBitmap in this browser decodes the JPEGs found inside a PDF.
  • That canvas re-encoding actually produces smaller images at the quality settings the tools use.
  • That transparent source pixels come out white rather than black — the classic bug in browser image pipelines.
  • That compressed output still contains selectable text, verified by re-parsing the result.
  • That the compressed sample is visually acceptable — press the download button and look at it.

If a test fails here but passes in Node, the problem is browser-specific. Note which browser and version in the issue — that information is most of the fix.
