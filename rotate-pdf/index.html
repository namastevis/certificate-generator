Why the rotation in your reader does not stick

Every PDF reader has a rotate button, and it almost never saves anything. It turns the picture on your screen and nothing else, so the moment you close the file — or email it to somebody — the page is sideways again.

A PDF page carries its own rotation value, and that is what has to change. This tool writes it into the document, so the page is upright for everyone who opens it afterwards, in any reader, on any device.

Nothing is re-rendered

Rotation is one number stored on each page. Changing it does not touch the text, the images or the vector graphics, so there is no quality loss and the file size barely moves.

Common questions

Is my file uploaded?

No. There is no server. Watch your browser's Network tab if you would like to check.

Only some pages are sideways. Can I fix just those?

Yes — list them in the pages box. For a double-sided scan where every other page is upside down, even or odd usually does it in one go.

I need different angles on different pages.

Use Organize PDF, which lets you turn each page individually on a visual grid.
