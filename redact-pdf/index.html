The mistake this tool exists to prevent

Drawing a black rectangle over a name does not remove the name. In a PDF, that rectangle is simply another object sitting on top. The text underneath is still in the file, still selectable, still copyable, and trivially extractable by anyone who thinks to try.

This has gone wrong publicly and expensively — court filings, government releases and corporate disclosures have all leaked names that somebody believed were blacked out. The information was never removed; it was only hidden from view.

What Kagaz does instead

Any page you mark is rendered to a flat image with the marked areas painted out, and the original page object is thrown away. The text, the images and the vector content underneath are gone from the file — there is nothing left to recover, because it is no longer there.

The price is honest and worth stating plainly: redacted pages stop being text. They cannot be selected, searched or read aloud by a screen reader. Pages you did not mark are copied through untouched and keep everything they had.

Before you send it

  • Open the finished file and try to select text in the redacted area. There should be nothing there.
  • Check the document's own metadata — a title or author field can carry a name you just removed from the page.
  • Remember that redacting a name in one place does not remove it from a header, a footer, or page 14.

Common questions

Is my document uploaded?

No, and here more than anywhere that matters. There is no server. Check the Network tab.

Can the boxes be lifted off afterwards?

No. There is nothing behind them — the page is a single flattened image with the content already removed.

Why does the file get bigger?

Because a page of text stored as text is tiny, and the same page stored as an image is not. Lower the resolution, or run the result through Compress PDF.

Can it find and remove every instance of a word?

Not yet. Search-and-redact across a whole document is on the roadmap.
